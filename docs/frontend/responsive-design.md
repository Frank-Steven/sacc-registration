# 多端响应式布局

> SACC 报名系统前端设计（[返回前端导航](index.md)）

## 一、设计原则

- **全功能，不删减**：手机 / 平板 / 桌面功能完全一致，仅适配交互形态与信息密度
- **移动优先**：报名、凭证、扫码、通知按移动端优先设计；管理端在移动端提供同等完整操作
- **一套代码**：断点只切换渲染容器，不改变路由、数据与状态层

## 二、目标设备与断点

| 端 | 断点（antd Grid） | 主要场景 |
|---|---|---|
| 手机 | xs <576 / sm ≥576 | 报名、凭证、扫码、通知、移动管理 |
| 平板 | md ≥768 / lg ≥992 | 审核、签到、管理操作 |
| 桌面 | xl ≥1200 / xxl ≥1600 | 管理端全功能、数据看板 |

## 三、布局适配

| 布局 | 桌面 | 移动端 |
|---|---|---|
| AuthLayout | 居中卡片 + 品牌区 | 全宽卡片 |
| UserLayout | 顶部导航 | 顶部简导航 + 底部 TabBar（工作台 / 活动大厅 / 我的报名 / 通知） |
| AdminLayout | 左侧固定菜单 | 汉堡按钮 → 抽屉菜单（全量菜单）；内容单列 + 底部固定操作条 |

- `useBreakpoint` 切换布局结构，路由与数据层不变
- 管理端所有操作移动端可用：菜单抽屉全量展示，操作按钮落入内容区

## 四、组件适配（全功能）

| 组件 | 桌面 | 移动端 |
|---|---|---|
| 名单 / 列表表格 | 完整表格 + 列冻结 | 卡片列表或横向滚动，操作触控化，多选批量可用 |
| FormBuilder | 多列栅格 | 单列堆叠，控件放大 |
| 分步报名 | 步骤条 + 表单 | 单步单屏，底部固定操作条 |
| 分组树（大厅 / 管理） | 常驻左侧 / 树面板 | 抽屉内展示，节点操作完整 |
| FormDesigner | 拖拽排序 | 触控长按排序，字段配置面板全屏 |
| 凭证二维码 | 弹窗展示 | 全屏亮码 |
| 审核 / 详情抽屉 | 右侧抽屉 | 全屏抽屉 + 底部操作按钮（通过 / 驳回） |
| 签到扫码 | 桌面可扫码 | 相机全屏扫码，连续模式 |
| 批量操作 | 表格批量栏 | 触控多选 + 底部批量操作条 |
| 上传（文件字段） | 点击上传 | 拍照 / 相册选择 |
| 数据看板 | 多图表网格 | 单图表纵向滚动 |
| 配置中心 | 表格 / 表单 | 单列编辑，按 `config_type` 渲染同款控件 |

## 五、专项场景（移动优先）

1. **手机报名**：底部固定"上一步 / 保存草稿 / 提交"操作条，防误触；必填即时校验
2. **移动端表单设计**：触控长按排序、字段配置全屏面板，功能与桌面一致
3. **移动端审核**：全屏抽屉查看明细 + 底部通过 / 驳回，支持批量
4. **扫码核销**：连续扫码（自动聚焦、扫码即核销），竖屏为主
5. **凭证出示**：全屏亮码 + 提高亮度提示
6. **通知触达**：站内信角标 + 邮件；可选 Web Push（服务端宿主支持时）

## 六、技术实现

- antd Grid 响应式栅格 + `useBreakpoint`
- 布局组件按断点分支渲染（UserLayout 底部 TabBar 仅 xs / sm 显示）
- 表格 / 卡片列表共用数据源，仅切换容器；批量选择状态共享
- 拖拽类组件（FormDesigner / GroupTree）桌面鼠标、移动端 `pointer` 事件 / 长按（如 `dnd-kit` 多输入支持）
- 移动端细节：视口 meta、`env(safe-area-inset-*)` 安全区、触控目标 ≥44px、防 300ms 点击延迟

## 七、性能与资源

- 图片懒加载 + 压缩，二维码按需引入
- 移动端首屏优先报名路径（活动详情 → 报名表单）
- 各断点共用缓存策略，不重复请求
