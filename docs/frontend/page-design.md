# 页面设计

> SACC 报名系统前端设计（[返回前端导航](index.md)）

## 一、页面清单总览

| 模块 | 页面 | 核心内容 | 角色 |
|---|---|---|---|
| 账号 | 登录 / 注册 / 忘记密码 | 失败锁定、重置流程 | 公开 |
| 报名端 | 工作台 / 活动大厅 / 详情 / 报名 / 我的报名 / 凭证 | 多步骤表单、草稿、候补、取消 | 用户 |
| 通知 | 通知中心 / 偏好设置 | 未读角标、渠道偏好 | 用户 |
| 资料 | 个人资料 / 常用信息 | 预填维护 | 用户 |
| 活动管理 | 列表 / 编辑（表单设计器）/ 模板 | 动态表单配置、复制 | 管理员 |
| 报名运营 | 名单 / 审核 / 签到 / 看板 | 批量审核、核销、统计 | 管理员 / 审核员 |
| 系统管理 | 看板 / 分组 / 账号 / 角色 / 配置 / 审计 / 数据治理 | 分组树、授权、配置中心 | 超管 |

## 二、布局框架

三种布局（多端适配见 [responsive-design.md](responsive-design.md)）：

| 布局 | 适用 | 结构 |
|---|---|---|
| AuthLayout | 登录 / 注册 / 忘记密码 | 居中卡片 + 品牌区 |
| UserLayout | 报名端 | 顶部导航（Logo、活动大厅、我的报名、通知角标、头像菜单）+ 内容区 |
| AdminLayout | 管理端 / 系统管理端 | 左侧菜单（按角色渲染）+ 顶栏（面包屑、用户）+ 内容区 |

## 三、报名端页面

**我的工作台 `/workbench`**
- 快捷入口：活动大厅 / 我的报名 / 常用信息
- 我的报名卡片：状态分组 Tab（草稿 / 待审核 / 已通过 / 候补 / 已取消）；草稿显示"继续填写"、候补显示排名、未通过显示"修改并重新提交"

**活动大厅 `/activities`**
- 左侧：分组树（嵌套分组折叠，按 `group` 树）
- 右侧：活动卡片列表（名称、形式标签、报名时间、名额进度、状态）
- 筛选：分组 / 形式 / 状态 / 关键字

**活动详情 `/activities/:id`**
- 活动信息：名称、形式（`activity_type`）、时间、按形式展示场地或参会链接
- 报名信息预览（字段只读）
- 报名按钮按状态控制：未开始 / 进行中 / 已截止 / 已满 / 已报名
- 订阅提醒开关

**报名表单 `/activities/:id/register`**
- 步骤条（多表单按 `sort_order`）
- 每步一个动态表单（FormBuilder）：字段按 `form_field` 渲染，含校验 / 联动 / 文件上传
- 预填：基础资料（`user`）+ 常用信息（`user_common_info`），可修改
- 底部：上一步 / 下一步 / 保存草稿 / 提交
- 提交后按 `need_review` 显示"待审核"或"报名成功 + 凭证二维码"

**我的报名 `/my-registrations` + 详情 `/my-registrations/:id`**
- 列表 + 状态筛选
- 详情：凭证（`receipt_no` 二维码）、修改 / 取消按钮（按 `allow_modify` 与状态机控制）

**通知中心 `/notifications`**
- 未读 / 全部 Tab；点击跳转关联对象（审核结果 → 报名详情）

**个人资料 `/profile`**
- Tab：基础资料（`user`）、常用信息（`user_common_info` 增删改）、通知偏好（`user_notify_pref`）

## 四、管理端页面

**管理员待办 `/admin/workbench`**
- 统计卡：待审核数 / 候补数 / 今日报名数
- 待审核快捷处理列表

**活动管理 `/admin/activities`**
- 表格：名称、形式、时间、名额、状态、报名数
- 操作：编辑 / 复制 / 名单 / 看板 / 软删（二次确认）

**活动编辑 `/admin/activities/:id/edit`**
- 基本信息：名称、形式、时间、名额、`need_review`、`allow_modify`
- 表单设计器（FormDesigner）：多步骤表单管理、字段拖拽配置
- 场地 / 参会：按形式显示对应配置
- 分组关联：分组树勾选
- 扩展配置：`activity_config` 键值（ConfigEditor）

**报名名单 `/admin/activities/:id/registrations`**
- 表格：列按 `form_field` 动态生成，状态筛选、字段值筛选
- 批量：通过 / 驳回 / 导出 CSV
- 行操作：详情抽屉、审核

**审核队列 `/admin/activities/:id/review`**
- 待审核列表 + 详情抽屉：字段明细、通过 / 驳回（理由必填）、批量

**签到核销 `/admin/activities/:id/checkin`**
- 按 `checkin_mode`：线下扫码（CheckinScanner）/ 线上手动核销列表
- 已签到标记、重复签到提示

**数据看板 `/admin/activities/:id/statistics`**
- 图表：报名趋势、状态分布、专业分布、名额使用率

**表单模板 `/admin/templates`**
- 模板列表 + 模板编辑（字段快照 JSON）+ 一键套用（选择目标活动）

## 五、系统管理端页面（超管）

| 页面 | 路径 | 要点 |
|---|---|---|
| 全局工作台 | /admin/overview | 活动 / 报名 / 活跃用户 / 存储占用统计卡 |
| 分组管理 | /admin/groups | 分组树拖拽编辑（嵌套） |
| 账号管理 | /admin/users | 搜索、禁用 / 启用、代重置密码 |
| 角色与授权 | /admin/roles | 角色分配 + 分组范围选择 + 权限预览 |
| 配置中心 | /admin/config | `system_config` 键值编辑（按 `config_type` 渲染控件） |
| 审计日志 | /admin/audit-log | 按操作人 / 对象 / 时间筛选 |
| 数据治理 | /admin/system | 备份 / 恢复、活动归档、全量导出 |
