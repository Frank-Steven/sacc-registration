# 体验设计（按角色）

> [返回总入口](README.md)

三类角色的改进均落在 API + 前端功能，表结构支撑仅 3 项：`user_notify_pref`、`registration.checkin_time`、`form_template`。

## 一、普通用户（报名者）

| 改进 | 说明 | 表结构支撑 |
|---|---|---|
| "我的报名"工作台 | 草稿 / 待审核 / 已通过 / 候补 / 已取消分组展示；草稿断点续填；候补显示排名 | 无 |
| 通知中心 + 偏好 | 未读角标；每类通知开关与渠道选择 | `user_notify_pref` |
| 驳回一键重提 | 未通过通知内"修改并重新提交"，预填原内容 | 无 |
| 取消二次确认 | 提示"名额将释放"；候补者提示取消后不再自动递补 | 无 |
| 凭证二维码 | 报名成功生成 `receipt_no` 二维码，现场核销 | `registration.receipt_no` |
| 常用信息管理页 | `user_common_info` 增删改；报名时勾选"保存为常用信息"**未实现** | 无 |
| 截止感知 | **未实现**：无报名页倒计时 / 已截止灰化，活动详情仅展示报名窗口文案 | 无 |
| 场地 / 参会指引 | 线下显示地址，线上显示链接 | `activity_type` + `activity_config` |

## 二、管理员（活动管理员）

| 改进 | 说明 | 表结构支撑 |
|---|---|---|
| 概览看板 | `/admin` 实为跨活动概览看板（活动 / 报名 / 待审 / 候补 / 已签统计），非「待办工作台」 | 无 |
| 批量审核 | **未实现**（后端无批量接口，逐条审核） | 无 |
| 名单 + 签到 | 导出名单（CSV / 全量分块）+ 凭证扫码 / 手动补签标记已签到 | `registration.checkin_time` |
| 表单设计器 | 表单组 Collapse 列表 + 字段 Modal 编辑 + 上移 / 下移（无拖拽 / 复制字段 / 实时预览） | 无 |
| 模板复用 | 保存表单模板，新活动一键套用 | `form_template` |
| 活动复制 | **未实现**（无 `activity.copy`；以「保存为模板 + 新建 + 套用」组合实现） | 无 |
| 数据看板 | 指标卡 + 状态分布 + 字段分布 + 趋势折线（7/30/90 天；无专业分布 / 名额使用率） | 无 |
| 名额预警 | **未实现**（名额使用 ≥90% 通知管理员） | 无 |

## 三、超级管理员

| 改进 | 说明 | 表结构支撑 |
|---|---|---|
| 全局工作台 | 活动 / 报名 / 活跃用户 / 存储占用概览 | 无 |
| 分组树管理 | 嵌套分组可视化拖拽编辑 | 无 |
| 账号管理 | 搜索、禁用 / 启用、代重置密码 | `account.status` `reset_token` |
| 权限预览 | 选中用户显示权限判定结果（递归解析可视化） | 无 |
| 配置中心 UI | 按 `config_type` 渲染编辑控件 | `activity_config` `system_config` |
| 审计日志检索 | 按操作人 / 对象 / 时间 / 类型筛选 | `audit_log` |
| 数据治理 | 备份 / 恢复、旧活动归档、全量导出 | 无 |
